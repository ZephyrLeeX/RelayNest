## 最小范围与实现选择

原 S03 禁止修改公共 auth，不能在原范围内完整解决本问题。本修复卡明确允许以下五个主要文件（以及本任务实施报告），不扩大到其他认证/存储实现：

1. `server/internal/auth/request_security.go`：新增固定 REQUIRED 语义的 `AuthorizeRequired` 与 `WriteSessionErrorRequired`；原 `Authorize` / `WriteSessionError` 保持 FAILED 默认。两组薄包装共享私有授权/会话错误映射逻辑，仅选择 401 机器码；不接受调用方任意字符串，不改变凭据、来源、CSRF、Inspect 或错误分类顺序。
2. `server/internal/auth/request_security_test.go`：验证两种响应选择、401 错误类别和原入口不变，覆盖真实管理员及真实 Bot 凭据。
3. `server/internal/devices/http.go`：仅 DELETE 的 Authorize 和事务错误输出改用上述 REQUIRED 入口；GET 两处维持原行为。
4. `server/internal/devices/http_test.go`：增加真实 mux/SQLite DELETE 全部 401 路径、失败副作用与 GET 对照；纠正原 DELETE 错码断言，保留既有矩阵。
5. `server/cmd/relaynest/main_test.go`：扩展真实 production 装配的 DELETE 机器码及 GET、既有 auth/Bot 路由对照，保留原组合验收。

沿用 `*auth.RequestSecurity` 注入，新增方法即最小 Go 能力扩展，不改变已有签名或启动接口。禁止 HTTP 正文截获改字符串、复制认证 SQL、引入全局响应框架、改 API/README 掩盖差异，禁止改迁移/依赖/registry 或其他项目。若五文件不足，先向调度交精确增补原因，不顺手扩写。

## 必验矩阵

| 路径 | 验收 |
| --- | --- |
| 入口缺失/空/格式错误/重复/混合凭据 | DELETE 返回 401 `AUTHENTICATION_REQUIRED`；使用有效目标 ID 避免掩盖认证路径。 |
| 随机 Bearer、无效 Cookie、过期 idle/absolute、已撤销、管理员代次失效、真实 Bot API Token/Webhook Key | 在来源合法时逐项验证 DELETE 的 401 精确码；公共 `ErrInvalidSession` / `ErrNotInitialized` 的 REQUIRED 映射也有明确断言。 |
| 请求检查成功后 actor 失效 | 真实 SQLite 中在业务复核前撤销、代次失效或到期，DELETE 最终仍 401 REQUIRED；覆盖事务入口、尾检和自撤最终复核的会话错误映射。复用受控时钟/现有真实事务测试证据，不以 sleep 或 stub 成功冒充。 |
| 来源/CSRF/故障 | 非法 Origin/Referer、代理与缺失/错误/重复 CSRF 保持 403 FORBIDDEN；Inspect/事务数据库故障保持 503 SERVICE_UNAVAILABLE。不得将所有错误归为401；目标失效仍404。 |
| 所有拒绝 | no-store，无 Set-Cookie、无 idle 续期、无目标撤销/其他写副作用、无失效通知；对测试主动注入的 actor 变动单独记录基线，不能把该变动当业务副作用。 |
| 旧消费者 | GET 及旧 Authorize/WriteSessionError、现有 auth/Bot 路由的精确旧码与状态不变；保留 Cookie、CSRF、来源、跨 store/issuer actor 绑定等原安全测试。 |

延迟失败优先用测试受控请求体在 Authorize 后、Revoke 前触发真实失效（读取后 EOF），以及 auth 包已有 `TestDeviceSessionRevocationCommitBoundaries` / queued invalidation 证据；不得为注入测试增加生产钩子。若尾检 HTTP 覆盖需更多测试入口，由实现者给证据后调度评估最小补充，不能声称只测映射等于已端到端覆盖所有时序。

保留 S03 完整分页、同安装 S1/S2/其他安装 B、重登旧 ID、不泄露 Token、Cookie 清除/代理 Secure、提交后 hook、启动关闭重开矩阵，以及父 A 撤销不影响 B、旧会话后续失败、无 Token 返回三项。真实 WS/provider/Android 真机仍 NOT_RUN；不消费 G1C01 草稿 API/header。
