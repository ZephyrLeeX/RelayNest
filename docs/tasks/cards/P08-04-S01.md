3 主要实现文件：`android/app/src/main/kotlin/top/jianxinli/relaynest/core/network/HubEndpoint.kt`、`HubAuthDto.kt`、`HubClient.kt`；对应局部测试与本卡报告。

最小接线由本卡独占：`android/app/src/main/AndroidManifest.xml` 添加 INTERNET 并保留 allowBackup=false；`android/app/build.gradle.kts`、`android/gradle/libs.versions.toml`、必要依赖锁条目只添加架构已选 OkHttp 的固定兼容版本/必要测试配置。先依据官方固定 tag/POM 与当前锁核实，再记录精确版本、传递依赖、最小锁差异并独审；本规划不预定未经验证的版本。禁止升级既有工具链或已有锁定版本，禁止新框架；若无法兼容先回调度具体差异。无 MainActivity 写权限，不改服务端/API。

## 实现与验收

- HTTPS 地址规范化、有效自定义端口、IPv6；host大小写与显式443等价；保留路径前缀并参与绑定，不能用绝对 `/api` 丢失前缀。拒绝userinfo/query/fragment、无效端口和点段/编码分隔歧义；不通过DNS/IP、证书或重定向合并地址。按 PLAN01 地址规则覆盖测试。
- 复用已选 OkHttp，实现 login/session/logout DTO，使用现有 JSON 能力。登录请求精确发送 android/device_name/安装UUID，只有登录响应读取 access_token/Bearer；不虚构 instance_id/刷新端点。
- 认证请求关闭自动重定向和跨协议重定向（包括同源）；3xx显示地址错误，不重放密码/Bearer。保留标准TLS验证，禁止trust-all/明文降级；凭据仅显式绑定请求，不设全局认证器或跨后端CookieJar。
- 有限连接/读取/整体超时及响应上限，I/O在主线程之外且关闭响应；区分401/429/5xx、网络/TLS/格式错误，不自动重试登录/注销。
- 局部测试覆盖端口/路径/恶意地址、重定向目标零请求、DTO字段与错误映射。测试夹具只证明客户端边界；真实服务由S04验证。核心版不要求RelayShelf配置。
