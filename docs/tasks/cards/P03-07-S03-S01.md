目标输入≤8k、硬上限12k tokens。先 `rg -n` 定位再读行段：PRD §3.4/§3.6；T3.1/3.2 的 admin/settings、版本/错误/权限，T5.4 清理保护与 T6 changes 分类；架构 §1/§4.3/§5；P06-08 配置职责。只读原 P03-07 规划报告“admin/settings/设置变更”缺口行和设备父完整交接摘要，不整读报告。

## 工作与验收

- [ ] 冻结 `GET/PUT /admin/settings`：唯一管理员 Bearer/Web Cookie、Cookie 写 CSRF/同源；默认保留30天、图片10MiB/文件50MiB可调；expected_version CAS、服务端时间/版本、冲突最新版本与重读恢复，正反例覆盖越权和过期版本。
- [ ] 清理缩短期限不承诺同步完成；依 T5.4/P06-08 保留未完成/未ACK/failed及其必要附件和引用保护，无静默清理授权或永久恢复承诺。按已批准正整数规则和经独立审计技术边界冻结契约，不把默认值作为绝对上限。
- [ ] 完成全局设置变化的明确类型分支/版本/获取配置关联，按 T6 逐类核对全部 changes；正文读取沿既有权限，不以同步绕过管理权限，不留任意object或悬空ref；复用设备 S02 已冻结分支，不重做设备通知。
- [ ] 报告移交 P06-08 配置/清理语义及 P4/P5/P8/P9 需要的契约；交下一卡仅 settings/change/error/version keys 与集成摘要。
