# P08-04-S03 登录状态与最小 Compose 接入

## 目标、依赖与上下文

组合基础能力，完成核心版地址、登录、恢复、过期与注销。强依赖 [S02](P08-04-S02.md) 独审集成（传递S01及服务基础）；可与完整P04-05设备分支并行，不承诺同地址部署替换隔离。

读根 AGENTS、CONTRIBUTING、[WORKER_PROTOCOL](../WORKER_PROTOCOL.md)、[父卡](P08-04.md)、[PLAN01](../reports/P08-04-PLAN01.md)、T7.1/T9、PRD4.4与C-05、S01/S02交接及 MainActivity 局部。默认输入4–7k且≤12k、总窗口≤60%，≥25%交接；超预算先拆。

## 允许范围与接线归属

5 主要文件：`android/app/src/main/kotlin/top/jianxinli/relaynest/feature/auth/AuthRepository.kt`、`AuthViewModel.kt`、`AuthScreen.kt`、同包根 `MainActivity.kt`、必要 `android/app/build.gradle.kts`；对应局部测试与本卡报告。Gradle仅补已有锁内同版本 lifecycle-viewmodel/协程等必要直接声明，若配置必须补锁则只加对应配置，不升级已有版本。复用主题，不建空模块；S01先拥有网络Manifest/Gradle，S03后接入口，避免并发共同写入。

## 实现与验收

- Compose → ViewModel → Repository 单向状态；区分未认证、登录中、恢复校验、已认证、失效与可重试网络错误。只有Hub配置，不要求RelayShelf；不提前实现双后端登录。
- 密码仅短暂内存，不经rememberSaveable/SavedStateHandle、磁盘/日志，提交后或离开清理。安装UUID来自S02，每次登录使用服务返回新Session.id。
- 恢复先GET session验证再展示已认证；401结束本地会话并显示重新认证原因。网络/429/5xx不冒充撤销或登录成功，不缓存密码重试。logout尝试服务端注销并结束本地会话；离线明确服务端未确认，不能声称离线远程撤销成功。
- 地址切换/注销立即隔离内存与持久凭据，取消旧请求或丢弃旧代次结果，迟到响应不能复活或覆盖新身份；会话终止信号留给后续同步任务，不在本卡实现发送/outbox。
- 状态测试覆盖成功/失败/恢复/过期、断网注销、地址切换与迟到响应；基础三端点的真实服务证据由S04汇总，不用桩冒充组合验收。
- 当前DTO无部署ID，同地址部署替换不能在发送旧Bearer前识别；不以一次401宣称识别成功，不新增服务字段。D01未决不影响基础开发，但阻止S04部署隔离及父卡放行。

## 检查、禁止事项与交接

运行局部状态测试及既有mise下 `cd android && mise exec -- ./gradlew :app:lintDebug :app:assembleDebug --offline`，可用环境检查Compose入口；缺环境如实NOT_RUN/blocked。真机、Keystore真机/成功release签名留最终验收。

不改服务端/API、RelayShelf/MP、推送/同步或工具版本，不写registry/推送部署。状态/owner/固定基线以 [registry](../registry.json) 为准，登记且依赖集成后才派发。独立提交本卡路径及 `docs/tasks/reports/P08-04-S03.md`；报告命令/环境/结果、基线/实现SHA、状态接口、逐项验收和遗留项；交不同agent独审及精确集成，父卡不自动done。新身份/安全/外部接口政策交调度询问用户。
