## 本任务工作

1. 实现随机会话摘要、Web/Android 登录响应、绝对/滑动过期和 logout。
2. S01 完整承担持久化生命周期、撤销和代次并发一致性；S02 消费已审计实现，承担冻结 HTTP 契约、凭据校验及端到端收口。具体边界、派发前核查见子卡与 [PLAN01 报告](../reports/P04-02-PLAN01-implementation.md)。
3. 父卡保留原验收并核对两卡组合：期限、续期、注销、重启持久性和重置并发无缺口；子卡 done 不自动替代父验收。P04-03 完整 CSRF/Origin/可信代理、P04-04 限流/公共日志仍为后续任务；三条路由的冻结安全要求不得延后或降级。
