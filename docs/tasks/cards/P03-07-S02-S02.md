## 目标与串行依赖

父卡：[P03-07-S02](P03-07-S02.md)，完整覆盖父验收2、3，及5/7/8注册相关部分。将注册写入、恢复读、条件删除、持久版本屏障留在同一接口/事务卡，禁止按API文件或端点拆开。依赖[S02-S01](P03-07-S02-S01.md)不同agent审计PASS并精确集成；继承S01父收口与规划登记前置，不依赖父S02 done。当前仅预规划，实施采用直接前卡集成后的最终main SHA，重验基数。

## 冻结输入与最小上下文

继承父卡共用规则，目标输入≤8k、硬≤12k；只取前卡≤800字交接、审计PASS/集成范围，不重读历史报告。冻结会话身份/代次失效和通用Sequence/Version/权限/时间/no-store；注册新增keys由本卡在既定需求内统一定义，不从规划卡猜未来名。

定向读取：T3.1～3.2（85～131）通用权限/条件请求相关行，T7.1（262起）代次隔离，T9.3（324～335）注册键、写入、更新/删除、撤销和job快照及条件结果段；T9.1（296～304）仅FCM补偿边界。API取前卡会话/撤销新增keys、`Version/UTCDateTime/Error`及所用身份/错误引用，不读SyncChange完整union。examples按provider/CAS/会话索引取局部；validate.py只取本卡新声明/Schema断言邻近段。

允许写四API文件 `server/api/openapi.yaml`、`server/api/examples.json`、`server/api/validate.py`、`server/api/README.md` 及 `docs/tasks/reports/P03-07-S02-S02-*.md`。两requirements锁只读，父卡全部禁止事项适用。通知偏好CAS/模式、同步设置分支和完整发送快照归下一卡；本卡仅完整冻结条件解绑所需注册/会话版本及内部结果边界，不新增HTTP后台job接口或厂商payload接口。

## 工作与验收

- [ ] `PUT /devices/current/push` 加当前会话限定的最小恢复读、条件删除完整路径/状态/Schema。普通命名在实施时依现有契约合理选择，交接枚举；不得接受客户端指定其他设备/会话。
- [ ] 每provider独立token、registration_version、expected_version、服务端updated_at和会话代次；多通道并存，省略其他通道保持，不作全量替换。相同注册版本同内容幂等；旧版/同版异值冲突。
- [ ] 明确初次/缺失记录CAS、删除后恢复读取与迟到写入的冲突行为、版本耗尽不回绕/不部分提交及重登录隔离。删除不能清掉版本屏障，恢复读不得回显token/凭据。完整注册事务不可留下待下一卡补的CAS/删除空洞。
- [ ] 条件删除仅解绑发送快照的provider/注册代次；区分客户端条件删除和服务内部发送失败解绑。轮换后迟到UNREGISTERED、网络错误/未知结果不得删新token、其他provider、会话或通知偏好；不暴露后台job动作或厂商错误串。
- [ ] 正反夹具覆盖多通道并存/局部更新、同值幂等/旧版/同版异值、初始/删除后重建/恢复读、旧失败解绑/迟到注销、会话撤销后重登与其他设备越权、版本耗尽；敏感字段不可回显。声明夹具不冒充运行时并发。
- [ ] 枚举新增恢复读/条件删除路径、权限/状态/Schema、CAS冲突恢复、条件解绑所需快照keys及内部边界；保留会话卡全部行为，未实现模式和通知设置不得宣称完整S02。
