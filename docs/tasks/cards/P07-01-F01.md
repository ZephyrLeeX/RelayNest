## 问题与证据边界

默认 `fetch` 保存为实例属性后以 `this.transport(...)` 调用，原生 Window.fetch 收到 AuthClient receiver，抛出 `Illegal invocation`；浏览器没有发出认证 API 请求。Node 注入桩的原 4 项测试漏测该差异。

A01 首轮原脚本失败、同页直接 fetch 返回 401，以及临时绑定 preload 后保留全部断言通过，均为报告明确继承的真实诊断证据。绑定 preload 的通过只定位原因，不能算原实现 PASS。A01 恢复收口时 `/tmp` 证据与私有库/字体已清除，本轮浏览器为 NOT_RUN；实施者必须重新产生证据。
