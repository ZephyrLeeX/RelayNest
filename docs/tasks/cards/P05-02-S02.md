## 工作

正式注册唯一 `POST /api/v1/bot/messages`（createBotMessage）。使用真实 API Token 发现并固定 Bot 身份，启用/send/提交前凭据代次仍须验证；Webhook Key/AdminBearer/Cookie不可混用。Bot忽略Android实例头，不据其切换身份；BotID只取认证身份，body不可指定。调用S01同事务创建，commit后201 Message+no-store，不虚构ACK/执行成功。

冻结请求上限256KiB、UUIDv4幂等头、未知/结构400、语义422、超限413、未授权401、能力403、资源域404、异摘要409 IDEMPOTENCY_CONFLICT、墓碑410 RESOURCE_EXPIRED、存储503；遵循冻结 Error DTO/request_id/retryable，日志不含凭据/正文。默认值与摘要一致；当前有限文本范围外显式拒绝并报告，不能吞字段或宣称完整载荷通过。
