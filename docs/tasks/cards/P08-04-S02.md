# P08-04-S02 安装身份与 Keystore Bearer 存储

## 目标、依赖与上下文

实现 T7.1 既定安全存储。强依赖 [S01](P08-04-S01.md) 独审集成（传递 P03-03/P04-04/P04-05-S01）；只提供存储，不接UI或远程设备管理。

先读根 AGENTS、CONTRIBUTING、[WORKER_PROTOCOL](../WORKER_PROTOCOL.md)、[父卡](P08-04.md)、[PLAN01](../reports/P08-04-PLAN01.md) 安全/身份段及官方资料、T7.1/T9、S01 endpoint/DTO与交接、现Manifest。默认输入4–7k且≤12k、总窗口≤60%，预留≥25%交接；超预算先拆。

## 允许范围

3 主要文件：`android/app/src/main/kotlin/top/jianxinli/relaynest/core/security/InstallationIdentity.kt`、`SessionCipher.kt`、`SessionStore.kt`；对应测试与本卡报告。无 Manifest/MainActivity/Gradle/锁写权限，不引入安全框架，不改服务端/API。

## 实现与验收

- 每安装UUID，保存在应用私有且不备份的位置；重装不得从备份恢复旧会话。device_id不等于session.id。
- 使用 AndroidKeyStore AES/GCM/NoPadding、系统随机IV；密文/IV原子保存在 noBackupFilesDir；保存规范化endpoint和当前Session.id必要元数据并绑定加密关联数据，防止密文移用。不声称该绑定提供服务端实例身份，不新增生物识别/StrongBox强制政策。
- 仅保存Bearer和必要元数据，不保存密码，不入普通日志/备份。密钥失效/缺失、密文损坏或绑定不符时安全清理并要求重新登录，不降级明文；单会话清除与安装身份分开。
- 只恢复同绑定地址记录；换地址不附旧凭据。读写/清除原子化，与S03约定代次控制，不让迟到登录复活已注销会话。不为其他后端复用凭据。
- 测试加密封装、损坏/绑定错误、原子清除/恢复；AndroidKeyStore执行证据必须注明环境，不用mock证明硬件保障。未到最终真机验收则Keystore真机NOT_RUN。
