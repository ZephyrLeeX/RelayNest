3. 原任务工作和下列全部原验收保留。原验收 1 由 S02 真实 HTTP 与 S01 独立授权共同覆盖；原验收 2 由 S01 摘要持久化与 S02 创建/读取响应覆盖；原验收 3 由 S01 send/receive 检查与 S02 路由拒绝覆盖；原验收 4、5 在两子卡及父级收口分别落实。S01 单元通过不能冒充跨路由、管理员认证或父卡通过。

无环顺序：`P03-07 + 本规划审计集成 + P05-01-S01 已审计集成 → S01`；`S01 + P04-02 + P04-03 → S02`；`P04-02 + S01 + S02 → 本父卡收口`。父子归属不是依赖边；S01 不依赖父卡 done。P05-01-S01 尚需调度经 P05-01-PLAN01 独审集成后登记并交付实际实现审计集成 SHA，当前不宣称 S01 ready。详见 [规划报告](../reports/P04-06-PLAN01-implementation.md)。
