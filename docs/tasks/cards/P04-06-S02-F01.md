## 问题与冻结契约

A01 在真实 TLS / 生产授权 / SQLite fixture 中复现：POST `Name` 或嵌套 `Send` 返回 201，PATCH `EXPECTED_VERSION` / `Enabled` 返回 200，且数据库改变。`DisallowUnknownFields` 仍接受大小写别名，现有 RawMessage map 仅检查 null。

只恢复既有 `server/api/openapi.yaml` 的 createBot / patchBot 和以下 `additionalProperties: false`，不建立新的大小写政策：

| 对象 | 精确允许键 | 既有必填键 |
| --- | --- | --- |
| CreateBotRequest | name、enabled、capabilities | 三者均必填 |
| PatchBotRequest | expected_version、name、enabled、capabilities | expected_version |
| 两请求内 Capabilities | send、receive | 两者均必填 |

键名按 JSON 解码后的属性名精确核对；逐层拒绝未声明键，再沿用既有类型、必填、null 和业务验证。不能只依靠 Go 字段匹配。冻结契约没有新增 duplicate JSON policy，本卡不扩展重复键设计或改变现有处理。
