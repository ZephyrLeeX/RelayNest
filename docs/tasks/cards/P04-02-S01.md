## 本任务工作

1. 随机会话原值至少 256 bit，仅持久化 SHA-256 摘要；可撤销数据库会话，禁止 JWT 替代、明文 Token/密码入库及凭据/CSRF 日志。仅向创建调用方交付本次必需的明文凭据。
2. 同一生命周期实现创建、鉴权、滑动续期、当前会话撤销、代次失效与重启读取；记录客户端、设备、闲置/绝对期限，提供 S02 所需会话元数据，禁止返回密码/凭据摘要。
3. Web 空闲 24h/绝对 7d，Android 空闲 30d/绝对 90d；仅有效请求续期，且不突破绝对期限；到期重新登录，失败请求不得复活会话。使用可控时间测试边界。
4. 创建时核对凭据校验所观察到的管理员代次，鉴权/续期/撤销以数据库状态为准。重置与登录创建、撤销与续期的竞争必须在本卡用事务或等价原子条件完整解决，不拆给 HTTP 层补救，不让旧代次会话在重置后有效。
5. 当前会话撤销不影响其它设备或 Bot 凭据。复用 P04-01 实际撤销协作点；推送映射/连接若尚无实现，记录后续接入点及限制，不伪造已有 WS/推送关闭验证，不新增这些子系统。
6. 向 S02 交付真实实现的调用入口、错误分类、时间/事务语义与夹具用法；不冻结未经实现的签名。HTTP 凭据验证后必须消费本卡代次保护，不能另写一套存储逻辑。
