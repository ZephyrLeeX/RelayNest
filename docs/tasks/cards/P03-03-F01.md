## 本任务工作

1. 复用 README 已约定的 `RELAYNEST_ANDROID_KEYSTORE_PATH`、`RELAYNEST_ANDROID_KEYSTORE_PASSWORD`、`RELAYNEST_ANDROID_KEY_ALIAS`、`RELAYNEST_ANDROID_KEY_PASSWORD`；提供实际消费者与明确的签名请求入口。debug 无配置仍可构建；仅设置部分配置不能被当作有效正式身份。
2. 对签名请求检查四项齐备及密钥文件引用的存在/普通文件/可读性；缺失、部分配置、无效引用清晰失败，不输出值、完整秘密路径、口令、别名或文件内容，不回退 debug 签名。提供不读取 keystore 内容的完整性诊断入口；通过该诊断只表示配置齐备及引用可读，不代表口令、别名或签名有效。
3. 按明确请求把配置接入 release signingConfig；不触发真实签名/发布。签名消费者与诊断的实际入口和无配置行为在 README 明确，不留下“环境变量只有说明没有消费者”的缺口；不改变应用包名、工具链、PoC 排除或业务范围。
4. 文档说明仓库外保管/安全备份、安全配置引用、受保护 CI 临时私有目录加载和作业结束清理；不向 PR/fork 暴露，不把秘密放命令行参数、仓库属性或日志。正式保管方案仍由用户确认，本卡不执行该方案或 CI 发布。
