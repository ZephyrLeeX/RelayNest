实际路径映射：`server/internal/auth/` 按需新增；CLI 复用 `server/cmd/relaynest/`；迁移规划路径 `server/migrations/` 即现有实际路径。保留 `0001_initial.sql`，下一迁移候选为 `0002_admin.sql`，由调度串行独占分配；准确文件名可按现有约定合理决定，不与其他任务并发抢号。存储复用现有 `storage.Open/Read/Write`，不搬目录或另建迁移入口。上述依赖文件、CLI、迁移和存储测试夹具是共同文件，派发时须协调独占写入。

## 本任务工作

1. 只实现管理员表、密码摘要和 init/reset-password。
2. 重置增代次，会话后续任务接入。
3. 管理员字段、CLI 数据库路径及代次类型实施时按已确认设计和最终契约核查；未确定的重要语义交回调度，不编造规则。需要超出上述范围时先报告，不自行扩展。

## 明确不做

- 不顺手实现前后阶段、全模块重构、另一个后端或真实发布。
- 不在本卡实现会话撤销接线或 WS 关闭；本卡只提供重置密码与增加代次的事务基础，后续任务接入。
- 不改变已确认需求/安全边界，不修改 RelayShelf 后端或 MP 核心，不加入业务命令/MCP。
- 不把源码推断、协议桩、模拟器结果写成外部系统或真机验证通过。
- 不接管总调度、不自行派生子agent或写入其他任务状态；有新工作交回拆分请求。

审计由另一个 agent 按 [统一协议](../WORKER_PROTOCOL.md) 执行，核对本卡范围、精确实现SHA、上述验收与越权/故障边界。审计不写代码；发现问题派修复卡，修复后重审。集成 agent 对最终变更组合做相关验证，总 agent 只调度。
