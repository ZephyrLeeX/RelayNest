## 工作与共同内部职责

- 唯一约束为身份+操作类别+UUID key，记录规范化请求摘要和稳定结果元数据。管理员为唯一管理员身份，Bot 为 BotID；不按 session、credential_id、generation 或 Token 字节分区。操作类别隔离，路径目标 Bot ID 入摘要。默认空 text/数组/null 规范化，保留实际文本和数组顺序，含全部有效字段，排除 Authorization，不自行 trim/改写 Markdown。
- 提供受信调用方同事务 primitive：当前授权/能力复核→查键/摘要→恢复原结果或冲突→复用 S03 真实 CreateApplicationTx/CreateAdministratorTx→记录结果；同一 sql.Tx，不调用另开事务的 CreateApplication 包装。管理员外层事务只能由 SessionStore.WithAuthorizedWrite 与后续 B01 绑定拥有，不新增公开管理员创建方法；Bot 查重前也须 AuthorizeTx。
- commit前仅候选，禁止对外发布。重试恢复原 message ID/序号/revision、管理员 delivery_id 及必要响应元数据，不再分配 UUID/序号/changes/delivery/push job；不拿已编辑当前消息替换原创建结果。不重做 S03 pending/快照。文本 UTF-8/限额/format 有效；非空附件/引用/按钮显式拒绝，空值仍规范化参与摘要，不提前实现其业务。
- 存活消息/投递记录不按7天删除。提供最小无正文墓碑表示及410 RESOURCE_EXPIRED结果，供未来清理同事务转换；不启动 retention worker、不缩短受保护记录寿命、不把正文留入墓碑。
