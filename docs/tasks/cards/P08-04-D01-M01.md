# P08-04-D01-M01 离线恢复克隆换ID与全会话撤销

## 派发与输入

实施卡；登记后派发，状态/owner/基线唯一来源 [registry](../registry.json)。基线SHA、工作树/分支由调度在派发时填写，必须包含依赖最终独审集成SHA，不能直接沿用规划基线。

依赖：[P08-04-D01-S01](P08-04-D01-S01.md)独审并精确集成。 各卡最终SHA由不同agent独审A01，PASS后I01精确集成；不得以被审任务done作为A/I前置形成环。

先读根AGENTS、CONTRIBUTING、[WORKER_PROTOCOL](../WORKER_PROTOCOL.md)、[获准提案](../reports/P08-04-D01-PLAN01.md)相关局部及其A01/I01、[拆卡报告](../reports/P08-04-D01-CONTRACT-PLAN01.md)、T3/5/7/8/9相关章节与前置摘要。提案历史“待批准”状态以本轮已明确批准记录为准；G1、生命周期、具体契约/成本全部获准，不重问。初始包5–8k且≤12k tokens，窗口≤60%、≥25%留交付；先索引再读3–5主要文件/测试，单工具输出≤800tokens/50行。超预算checkpoint，不能继续吞整API。

## 允许范围

server/cmd/relaynest/main.go、admin.go或独立instance维护入口、server/internal/auth/administrator.go及小型事务辅助、对应测试和最小离线操作文档（按C01已冻结命令），最多5主要实现文件。不得顺手重构密码重置或改既有auth策略。

## 工作与冻结接口

实现仅停服/隔离入口后的最小离线换ID命令，备份/停旧进程/独占操作/重启验证写入操作文档；在一个写事务内换ID、推进administrator.auth_generation、撤销全部管理员会话及现有推送映射，整体成功才提交。恢复与独立clone必须执行后才ready；清库新ID，原库无回滚停机迁移保留；不自动识别副本，不引入在线rotation API，不改Bot凭据或sync_epoch。
派发时先实证枚举实际session与push映射表/仓储及撤销路径。若push映射尚不存在，交付“当前无映射”的schema/源码证据、测试和未来注册/投递必须按实例+认证代次失效的强依赖门禁；不得编造表、擅建push功能或删除全撤销要求。维护不支持服务仍在运行/在线换库，测试确认独占失败安全退出；SQLite写锁不等于已证明所有服务停机，明确人工前置条件。

除C01外以C01最终冻结SHA为唯一契约；接口偏离先报调度，不自创需求。G1只覆盖诚实替换/误连，接受probe后瞬切旧Bearer/密码字节可能到B；随机公开ID不是秘密。保持Bot Hub传输边界，不改RelayShelf/MP，不做现网维护/部署，不写registry或他卡。

## 验收与失败边界

恢复备份（含旧撤销会话复活风险）/独立clone在离线换ID后，全部旧admin会话和实际push映射失效、重登必要；正常迁移不撤销。任一步生成/写入/提交失败整体回滚；并发维护/运行进程前置检查失败不部分提交；命令不输出ID/凭据/敏感DB路径。旧auth/密码重置非回归，不对真实部署执行。

## 检查、环境与交接

Go cmd/auth/storage相关测试及race；仅临时库/受控进程。保留未来push门禁证据；NAS缺失不挡局部实现，但无实机维护验收。

按协议报告命令/环境/结果、基线/实现SHA、契约冻结SHA、精确接口及未解决问题，证据写本ID报告。仅显式stage本卡允许路径并本地独立Conventional Commit；不push/新聊天/自行派agent。必需检查未跑不可记pass，独审/集成不自动代表父或S04完成。
