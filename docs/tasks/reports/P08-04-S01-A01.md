## 范围与结论

已读 AGENTS、CONTRIBUTING、WORKER_PROTOCOL 审计节、S01 卡、PLAN01 地址/传输/D01 规则及其 A01/I01、实施报告，定向核对 PRD4.4、技术设计7.1/9、真实认证 HTTP/OpenAPI 与路由；逐项检查 base→impl 全部10个变更路径、三主要 Kotlin 及两个对应测试。没有需要退回修复的编号发现；以下结论仅适用于本卡的地址与 HTTP 基础。

- **范围遵守。** 变化仅三网络文件、两个局部测试、Manifest、app Gradle、catalog、锁和实施报告。实际仍为单 app；INTERNET 为唯一 Manifest 增量且 allowBackup=false 保留。无 UI、存储、后端、RelayShelf、工具链或 registry 修改，无凭据和生产响应正文入库。
- **地址与绑定。** HubEndpoint.kt 在 HttpUrl 纠正之前检查原始 URI，拒绝 userinfo、query/fragment、空白/控制字符/反斜杠、越界/空/非数字端口、点段及编码点段、编码斜杠/反斜杠和二次编码入口。规范化 scheme/host/default443，保留有效自定义端口、IPv6、IDN 及基础路径。相对 api/v1/auth 拼接保留前缀；equals/bindingKey 按规范化 URL 隔离，session/logout 在目的地址不匹配时发送前返回 ADDRESS。不通过 DNS、TLS 证书或重定向合并地址。
- **真实协议。** server/internal/auth/http.go:33～83、httpapi/router.go:20～22 与 OpenAPI LoginRequest/Session/AndroidSession 一致：登录精确五字段、android 与 UUID；administrator 只有 username，session 包含实际元数据，只有登录读取 access_token/Bearer，并核对返回 device_id。session 无 token 响应可解码，logout 接受204。无 instance_id、刷新或部署探测接口。
- **传输与秘密。** 三端点共享关闭 followRedirects/followSslRedirects 的客户端，3xx 直接 ADDRESS，包括同源跳转。公开构造器保持平台 TLS，未引入 trust-all、明文 fallback、Cookie、全局认证器、缓存或隐式持久化。Bearer 仅在显式绑定的请求中添加；秘密对象没有自动 data class toString/copy，失败只公开枚举/状态/有限 Retry-After，不带异常文本或正文。
- **防重放。** retryOnConnectionFailure=false 加 login/logout isOneShot 正文，覆盖固定 OkHttp4.12.0 中即使关闭连接恢复仍可发生的503 Retry-After:0 follow-up。实测登录与注销各只产生一次请求；GET session 的库级安全重试不构成登录/注销重放。
- **资源与错误。** connect10s、read/write15s、call30s 有限；enqueue 回调处理网络与解码，未在调用协程线程阻塞网络。response.use 覆盖成功/失败，关闭期间 IOException 也映射 NETWORK/TLS；取消处理调用 call.cancel，保留协程取消语义。流以256KiB+1探测限制解压后正文，已知长度亦检查。统一映射401/429/5xx、3xx、其他HTTP、TLS/网络、JSON格式及超限；错误正文不被传播。取消/关闭竞态结论来自源码审查，未另做动态压力测试。
