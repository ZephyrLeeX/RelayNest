## 消费者交接

`bots.New(*storage.Store)` 提供 `Create/Get/List/Patch`，创建成功才返回严格 `bot/api_token/webhook_key` 三键及全局序号；普通查询仅公开元数据。List 是全量一致投影，HTTP 分页尚未接入。Create/Patch 的调用方必须先完成管理员授权。

`Authenticate(ctx,botID,Kind,secret)` 返回私有绑定字段的 `Identity`；Kind 为 `APIToken/WebhookKey`。`AuthorizeTx(ctx,*sql.Tx,Identity,botID,Operation)` 必须在未来 P05/P06 实际业务 `Store.Write` 回调内调用并传播错误，再提交业务写入；不能以请求开始的身份快照代替。能力取认证快照与当前数据库交集，撤权即时生效；Webhook 仅 Send，API 的 Send/Edit/Upload 要求 send，Claim/ACK/Renew/Download 要求 receive，Manage 拒绝。轮询不得跨网络持有事务，凭据重置须增加代次（未实现）。

真实错误为 `ErrInvalid`、`ErrNotFound`、`ErrConflict`、`ErrUnauthorized`、`ErrForbidden`；底层存储错误保留，HTTP 须按冻结契约脱敏映射，不能回显 SQL。Bot 写入、CAS 版本与公共 `changes.Append(ctx,tx,Metadata)` 同一事务，外层 Write 成功后才释放明文与序号；沿用已集成共同 changes 实现 `9041072` / 独审 `3314661` / main `b245192`。
