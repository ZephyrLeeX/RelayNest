## 管理员接口移交

`auth.ReadAdministrator(ctx,*storage.Store)`返回Administrator{Username,PasswordHash,AuthGeneration int64}，缺失ErrNotInitialized，存储错误ErrStorage；用户名原文区分大小写。`InitAdministrator(ctx,store,username,password []byte)`在单写事务检查/插入固定id=1、初始代次1，重复ErrAlreadyInitialized。`HashPassword([]byte)`、`VerifyPassword([]byte,encoded string) bool`采用Argon2id固定m65536/t3/p1与独立随机盐；verify并发槽2，上层仍负责登录限流。

`ResetPassword(ctx,store,password)`单写事务更新摘要并增加auth_generation，MaxInt64拒绝ErrGenerationExhausted且无部分更新；不含会话接线。CLI为`relaynest admin init --db PATH --username NAME`、`relaynest admin reset-password --db PATH`，秘密从终端或stdin单行输入，非命令参数。
