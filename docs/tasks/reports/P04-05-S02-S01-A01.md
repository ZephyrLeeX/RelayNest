## 编号发现

### P04-05-S02-S01-A01-F01 — P1：公开 Tx 鉴权没有约束实际复核所使用的 Store

- **位置**：`server/internal/auth/device_sessions.go:22–41,44–53`；对照 `server/internal/auth/session.go:183–205` 的实际查询和 `server/internal/storage/storage.go:109–122` 的事务创建/提交。
- **触发条件**：受信 Go 调用者把另一 `storage.Store.Write` 的 `*sql.Tx` 误接给原 SessionStore 的 `AuthorizeTx` / `RenewTx`；外库拥有匹配 actor 身份、token 摘要、元数据和有效期限的会话行及旧管理员代次。真实 RequestSecurity 必须先在原 Store 签发 actor；不要求伪造其私有字段。
- **独立实证**：使用两个文件 SQLite fixture。原库签发 actor 后，把该会话行复制到第二 Store；原库 `administrator.auth_generation` 改为 2，外库保持 1。原库 Write Tx 调用原 `s.AuthorizeTx` 返回 `ErrInvalidSession`；外库 Write Tx 调用同一个原 `s.AuthorizeTx` 却成功，随后同 Tx 写入真实 changes，再调用原 `s.RenewTx` 并成功提交；外库持久 count=1 且 idle 延长。固定实现的定向复验通过，表示成功复现该不期望的接受行为，**不表示安全通过**。
- **根因与影响**：29 行验证 `actor.store == s` 和 issuer/issued，仅约束 actor 与 SessionStore；32 行直接使用未绑定来源的外部 Tx。SQL 对所传 Tx 的数据库复核 generation/撤销/期限，未证明它是原 Store 当前状态。因而 actor 的私有绑定不能保证业务、changes、续期和源会话失效屏障属于同一 Store；原库重置后的旧 actor 可在错误接线中被另一数据库接受。这是公开 Go 事务边界的正确性问题，依赖受信调用方误接线/克隆状态，**没有证据表明远程请求可自行提交任意 Tx，也不影响内部自行持有 `s.store.Write` 的列表/精确撤销路径**。
- **与冻结验收的关系**：子卡第4项要求只在同一个 Store.Write 内复核、业务/changes/成功续期共同提交，并保留私有 Store 绑定；末段要求审计判断限制而非自动豁免。当前正确接线的原子性测试通过，只证明该前置条件成立时的行为，不能覆盖本反例。同内容外库无法从裸 sql.Tx 查询 owner 是该参数设计的限制，不是不可修复的结论，也不是已批准的边界收缩。
- **最小修复方向**：交规划/修复角色冻结一个由正确 Store 创建并持有事务的调用入口。例如由 SessionStore 开启其自身 `store.Write` 的受控回调，在同一回调提供业务 Tx 并统一进行入口/末尾鉴权续期；或由 storage 提供具有不可伪造 owner 绑定且生命周期受控的事务句柄，再由 auth 核对 owner。不能仅增加可复制的数据库标识行、第二次源库查询或要求调用者自报 Store：前两者分别仍可克隆或失去同一事务的竞争屏障。仅新增包装入口而保留不安全公开入口供下游继续使用也不足以关闭问题。具体接口由规划确认，审计未擅自扩大 scope。
- **复验要求**：把以下原库拒绝/克隆外库接受对照变成正式回归，修复后错误 owner 必须在业务写入/续期前被拒绝，或者 API 从构造上无法把外部 Tx 当作授权事务；验证外库无 changes、无业务写入/续期，原库失效仍生效。保留同 Store 成功提交及全部错误回滚、旧 actor/store/issuer/issued、并发重置/期限、自撤、hook 非回归，固定新 SHA 重审。
- **下游影响**：S03 不得把目前候选 Tx 签名作为已冻结安全契约；先规划修复/必要 scope 调整并独审。父 S02 暂不支持本地收口，不能交接 S03 或标 done。

```go
func TestAuditForeignTxAfterOriginRevocation(t *testing.T) {
    s, now := sessionFixture(t)
    meta, secret := createSession(t, s, "web")
    actor := deviceActor(t, s, secret, "web")
    other, _ := sessionFixture(t)
    deviceSQL(t, other, `INSERT INTO sessions(id,token_hash,auth_generation,client_type,device_id,device_name,idle_expires_at,absolute_expires_at,revoked) VALUES(?,?,1,?,?,?,?,?,0)`,
        meta.ID, deviceHash(secret.Token), meta.ClientType, meta.DeviceID,
        meta.DeviceName, meta.IdleExpiresAt.UnixNano(), meta.AbsoluteExpiresAt.UnixNano())
    deviceSQL(t, s, `UPDATE administrator SET auth_generation=2`)
    *now = now.Add(time.Hour)
    if err := s.store.Write(sessionContext, func(tx *sql.Tx) error {
        _, e := s.AuthorizeTx(sessionContext, tx, actor)
        return e
    }); !errors.Is(err, ErrInvalidSession) {
        t.Fatalf("origin did not reject: %v", err)
    }
    err := other.store.Write(sessionContext, func(tx *sql.Tx) error {
        if _, e := s.AuthorizeTx(sessionContext, tx, actor); e != nil {
            return e
        }
        if _, e := tx.Exec(`INSERT INTO changes(type,entity_id,revision,created_at) VALUES('audit.foreign','fixture',1,'2026-10-23T01:00:00Z')`); e != nil {
            return e
        }
        _, e := s.RenewTx(sessionContext, tx, actor)
        return e
    })
    if err != nil {
        t.Fatalf("foreign transaction rejected: %v", err)
    }
    if deviceInt(t, other, "SELECT count(*) FROM changes") != 1 ||
        persistedIdle(t, other, meta.ID) <= meta.IdleExpiresAt.UnixNano() {
        t.Fatal("foreign commit/renew missing")
    }
    t.Log("CONFIRMED: origin generation reset rejects actor; same actor succeeds and renews in cloned foreign Store.Write Tx")
}
```
