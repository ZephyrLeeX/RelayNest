## 变更及存储格式

只新增三个 `android/app/src/main/kotlin/top/jianxinli/relaynest/core/security/` 实现文件、对应 JVM 测试和本报告。未改 Manifest、MainActivity、Gradle、依赖锁、网络 DTO/API 或服务端。

- `InstallationIdentity(context).getOrCreate()`：`context.noBackupFilesDir/installation-id` 保存规范 UUID 文本；损坏时显式失败，不静默变更设备身份。独立于 Session.id，清除会话不删除此文件。
- `SessionCipher`：AndroidKeyStore 别名 `relaynest.hub.session.v1`，AES/GCM/NoPadding，仅 encrypt/decrypt、GCM、无填充、要求随机加密；不向 encrypt 传 IV，由提供者生成。解密缺键不创建替代键。没有生物识别、StrongBox 或硬件支持强制政策。
- `SessionStore`：`noBackupFilesDir/hub-session.v1` 是单地址单会话记录，DataOutputStream 编码依次为版本 int=1、规范化 endpoint 的 UTF、Session.id 的 UUID UTF、IV 长度 int/IV、密文长度 int/密文（含认证 tag）。AAD 为版本 int=1、同样的 endpoint UTF、Session.id UTF，长度编码避免串接歧义。仅 Bearer 被加密，不保存密码、管理员、设备名或会话有效期；元数据只含版本、地址、session.id 和解密必要信息。
- 同目录临时文件写入、文件描述符 sync 后 `ATOMIC_MOVE/REPLACE_EXISTING`，不支持原子替换时直接失败；无普通写文件降级。正常路径清理临时文件。清除同时删除密文和会话密钥；任一删除失败抛固定错误，不能报告持久清除成功。未声称已验证突然断电持久性。
- 有界解析（总记录 128 KiB、Bearer 16 KiB、IV 12 字节），拒绝错版本、截断、额外字节和异常长度。坏密文/错误 AAD/缺键或失效键/地址不符均先作废代次，再删除记录和键，返回未登录；无明文降级。

## S03 接口和并发约定

所有存储调用均是阻塞 IO，S03 必须在 IO 线程调用，不能在 Compose 主线程执行。生产构造只接收 Context，测试内部构造才允许临时目录与 JVM 密钥源。

1. `begin(endpoint): SessionAttempt` 每次作废所有旧票据，同地址登录重试也应调用；内存地址切换立即删旧记录/键。冷启动在 `restore` 核对磁盘地址，绝不将旧 Bearer 返回给另一个地址。
2. `restore(attempt): StoredSession?` 返回 `sessionId`、`credential`；没有记录或过期票据返回 null。损坏记录清理后票据失效，重新登录前必须重新 `begin`。恢复的凭据仍须调用 S01 的真实 session 端点验证，不能凭本地记录直接判定服务端会话有效。
3. `save(attempt, login): Boolean` 仅提交当前代次且凭据 endpoint 相同的登录结果；过期返回 false。写入或加密失败清理并抛固定错误（不附原异常或敏感值），S03 保持未登录。
4. `clear()` 用于主动注销，无条件先作废代次；`clear(attempt): Boolean` 用于对应请求的 401 等异步失败，过期票据返回 false，不能删除后来登录。
5. `isCurrent(attempt)` 用于 S03 在异步响应应用 UI/发布认证状态前复核。存储方法本身保证原子化，但 UI 状态也须由 S03 串行管理，不能将检查与迟到 UI 写入视为一个原子操作。每次登录重试/恢复/地址切换取得新票据，不能多次登录共用旧票据。

同一规范文件路径的 store 实例共享同进程锁和代次；当前 Manifest 无跨进程组件，不提供跨进程锁。代次仅进程内使用，不持久化；进程终止后旧网络回调也不会继续。安装身份与会话删除分离。

endpoint 和 Session.id 是本地目的地址/会话绑定，不是服务端实例身份；未新增 instance_id 或探测 API。D01 同地址部署替换识别仍待用户决定，本卡不声称解决。

## 官方 API 核对

2026-10-24 查阅 Android 官方 primary 文档：

- [KeyGenParameterSpec 的 AES/GCM 示例](https://developer.android.com/reference/android/security/keystore/KeyGenParameterSpec)：核对 AndroidKeyStore、AES/GCM/NoPadding、允许用途和无填充配置。
- [Android Keystore](https://developer.android.com/privacy-and-security/keystore)：密钥材料不可导出；是否由硬件支持取决于设备，本实现和 JVM 测试不证明硬件保障。
- [Context.getNoBackupFilesDir](https://developer.android.com/reference/android/content/Context#getNoBackupFilesDir())：目录不参与自动远程备份；现 Manifest `allowBackup=false` 未改。设备迁移/卸载重装实际行为仍留真机验收。
