## 内部行为复核

`DiscoverAPIIdentity(ctx, secret)` 以现有唯一 credential_id 且 kind=api_token 查询，完整 token SHA-256 常量时间核验后取得不可伪造的 Identity，仍须原 `AuthorizeTx` 在业务事务复核。原 `Authenticate`、`AuthorizeTx` 与 Webhook 规则没有改动，无新增凭据、表、索引、依赖或 HTTP/附件路由。

只有确定解析不能匹配、无 API 行或摘要不符返回 `APINoMatch`；依赖、取消与超时失败返回 `APIUnavailable` 和固定不可用错误。匹配后先固定 `APIMatched`，停用返回 ErrForbidden；后续能力拒绝、代次失效/轮换/撤销、跨 Bot 或依赖错误均不得由未来调用方解释成 Admin fallback。读事务报错时清空 Identity；已匹配则保留 APIMatched。形状仅服务内部解析，不授予身份，也不是稳定 wire 分流协议。
