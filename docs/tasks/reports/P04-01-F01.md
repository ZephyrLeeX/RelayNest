## 变更与范围

Linux 隐藏输入同步保存完整 termios 和文件状态标志，采用与锁定 x/term v0.47.0 相同的 ECHO/ICANON/ISIG/ICRNL 设置。只在该读取作用域订阅 SIGINT/SIGTERM，取消返回固定密码输入错误、退出码 1；正常、EOF、读取失败与取消统一恢复原状态，恢复失败返回错误且清理缓冲区。已取消的父 context 在读取前拒绝，读完后在打开数据库前再次检查。

读取使用非阻塞 FD 与 50ms poll，防止信号在 poll 就绪后清空输入导致 Read 阻塞；没有读取 goroutine，不关闭共享 stdin，也没有取消后迟到修改终端或消费后续输入的读取者。保留 x/term Linux 的退格、忽略 CR、LF 与部分输入 EOF 语义，stdin 单行处理和原密码政策不变。未改 main 的 HTTP 启动/优雅关闭、auth、迁移、依赖、API 或台账。

`password_linux.go` 只选中 Linux；`password_other.go` 保留其他平台既有 x/term 行为。既定部署为 NAS Docker Compose，CI Ubuntu；本次运行证据只适用于 Linux，未新增全平台已修复承诺。Windows 仅验证交叉编译，非 Linux 中断清理未运行/未声明修复。

变更路径：`server/cmd/relaynest/{admin.go,admin_test.go,password_linux.go,password_other.go,password_pty_test.py}` 与本报告；无其他修改。
