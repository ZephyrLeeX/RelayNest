## 发现

### P04-01-A01-01：P2，密码读取被 SIGINT 中断后不恢复终端回显

证据位置：`server/cmd/relaynest/main.go:21`（admin 分支使用 Background）、`server/cmd/relaynest/admin.go:70`（直接调用 term.ReadPassword）。Linux 的 x/term v0.47.0 `term_unix.go:88` 只通过 defer 恢复 termios；进程默认处理 SIGINT 直接退出，未执行 defer。本实现没有为 admin 分支安排中断清理。

触发：用户在隐藏密码提示期间按 Ctrl-C（等价 SIGINT），随后回到同一终端。影响：ECHO 保持关闭，后续 shell 输入不可见；init/reset 的常见取消路径不能恢复终端状态。正常输完密码可以恢复，开发报告中的正常恢复验证不能证明中断路径。

独立复现使用 Python 3.13.15 标准库和实际构建的 `/tmp/relaynest-p04-01-audit`：

```python
import os, pty, signal, subprocess, tempfile, termios, time
with tempfile.TemporaryDirectory() as d:
    master, slave = pty.openpty()
    original = termios.tcgetattr(slave)
    proc = subprocess.Popen([
        '/tmp/relaynest-p04-01-audit', 'admin', 'init', '--db',
        d + '/a.db', '--username', 'Admin'],
        stdin=slave, stdout=slave, stderr=slave, start_new_session=True)
    os.read(master, 1024)  # 等待提示
    time.sleep(.05)
    print(bool(termios.tcgetattr(slave)[3] & termios.ECHO))
    proc.send_signal(signal.SIGINT)
    proc.wait(timeout=3)
    print(proc.returncode, bool(termios.tcgetattr(slave)[3] & termios.ECHO))
    termios.tcsetattr(slave, termios.TCSANOW, original)  # 测试自行清理
    os.close(slave)
    os.close(master)
```

实际输出：提示期间 `False`；退出状态和退出后回显为 `-2 False`。临时数据库尚未创建。这里以明确 SIGINT 测试进程终止语义，不把 PTY 注入字节误当作已验证前台进程组的真实键盘事件。

修复方向：对 admin 隐藏输入生命周期建立可中断、可靠恢复的终端状态清理，避免只依赖 ReadPassword 正常返回；保持密码不回显、不进入参数/日志，不启动 HTTP。复验应增加 PTY 中断回归，覆盖 SIGINT（以及实现声明支持的 SIGTERM）、正常完成和输入失败，断言恢复原 termios、错误脱敏、取消不改数据库。审计不预设具体实现方案。
