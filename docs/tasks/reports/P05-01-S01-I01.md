## Bot 消费交接

包 `relaynest/server/internal/changes`：`Append(context.Context, *sql.Tx, Metadata) (Sequence, error)` 与 `Epoch(context.Context, *sql.Tx) (string, error)` 都使用调用方事务；在 `Store.Write` 中完成业务写入、版本更新和 Append，并返回任何追加错误。只有外层 Write 成功才可对外承诺序号。Epoch 只读既有持久值，不生成或修复。

`Metadata{Type Type, EntityID string, Revision int64, BotID *string, CreatedAt time.Time}`；BotID=nil 为 SQL NULL。`Sequence int64` 提供 ParseSequence/JSON 字符串边界；实体 Revision 仍是整数。八类为 MessageUpsert/MessageDeleted/BotUpsert/BotDeleted/ReadUpdated/DeliveryUpsert/DeviceNotificationsUpdated/SettingsUpdated；Type.ProjectionKeys 仅映射投影键，不提供完整 SyncChange。

`ErrInvalidSequence`、`ErrInvalidMetadata`、`ErrInvalidTransaction`、`ErrInvalidEpoch` 支持 errors.Is；底层 SQL/context/已结束事务错误保留，epoch 缺行保留 sql.ErrNoRows。完整精确参数、验证边界及调用约定见 [实现报告](P05-01-S01-implementation.md)，不得复制私有追加实现。
