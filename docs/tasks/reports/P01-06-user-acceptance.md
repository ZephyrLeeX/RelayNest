## 接受的缺口与限制

以下不再阻塞此次 P1 放行，原状态仍为 NOT_RUN 或限定验证，不补写 PASS：

- 自定义通知配置到目标插件的完整绑定；主动广播、管理员/用户路由完整覆盖。
- 助手正式安装后再次启动、从声明镜像重建、升级后重新应用及持久重放恢复；浏览器实际点击、线上恢复补丁并重启。
- v3.0.0 运行验证及其它版本；最低适配目标和拟议市场声明仍需与实际测试范围区分。当前补丁助手仅适配固定 v3.1.5 指纹，不支持据此宣称所有 >=3.0.0 版本兼容。
- 独立审计与原流程要求的独立集成验收。
- 正式 Hub/Android 按钮端到端、有效业务选择、真实搜索/订阅/下载及其权限/危险确认，不属于本次最小安全实测结果。

正式插件仍须绑定可信 Bot/user/request 身份；本次跨 Bot 结果依赖命名空间 userid，未证明宿主按 source 原生隔离。Hub 的职责及 MP 的业务权限/危险确认边界保持原约定。

现网仍使用恢复快照镜像，与 Compose 声明镜像不同；重建/升级可覆盖补丁。原 /netdisk 挂载经授权移除，相关功能需重新配置有效路径。此次验收不消除这些已记录的部署限制。
