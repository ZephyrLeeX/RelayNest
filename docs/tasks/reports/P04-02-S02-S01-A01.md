## 发现

### P04-02-S02-S01-A01-F01 — P2：登录未严格限制 JSON 字段名

- 位置：`server/internal/auth/http.go:89`（`DisallowUnknownFields` 与随后的结构体 Decode），字段定义在第 31 行。
- 冻结要求：OpenAPI `LoginRequest` 两个分支只允许列出的精确字段，`additionalProperties: false`；本卡要求严格 DTO、未知字段拒绝且拒绝无创建/Set-Cookie。
- 触发：将合法 Web 登录 JSON 的 `username` 改为 `Username`，保留正确密码与合法 Origin。Go 结构体解码默认接受大小写不敏感的字段别名，`DisallowUnknownFields` 不能提供该契约所需的精确键限制。
- 独立复现：固定提交快照、真实 TLS HTTP/SQLite 夹具中返回 **200、1 个 Set-Cookie、数据库快照改变**；契约应为 400 `INVALID_REQUEST`、无 Cookie/会话创建。请求还缺少契约要求的精确 `username` 键，却成功创建会话。
- 影响：认证请求验证与冻结 schema 不一致，未知字段拒绝的已有测试遗漏大小写别名。此问题不等同于绕过密码校验。
- 修复方向：解码前/过程中验证 JSON 对象精确键集合，不能只依赖结构体的 `DisallowUnknownFields`；保留已冻结错误与输入上限。添加大小写变体的真实 HTTP 回归，断言 400、稳定错误码、无 Set-Cookie、SQLite 快照不变。
- 复验：覆盖 Web/Android 字段别名（例如 `Username`、`DEVICE_ID`）与合法请求，并重跑相关 race/vet 检查。
