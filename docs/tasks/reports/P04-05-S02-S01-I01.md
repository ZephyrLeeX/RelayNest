## 下游准确接口和限制

- `WithAuthorizedWrite(context.Context, AdminRequest, func(*sql.Tx) error) error`：自身 Store.Write 中入口鉴权→受信业务及 changes→尾检续期→提交。BotS02 将既有 Create/Patch 的业务和 changes 置于回调，不另开外层 Write/嵌套事务；返回 nil 后才能公布结果/凭据。业务/CAS错误原样，鉴权 ErrInvalidSession，存储/提交 ErrStorage；一般业务自撤尾检失败回滚。回调同步用给定 Tx、关闭 Rows、不自行 Commit/Rollback/保留/另开事务；不提供恶意 Go/SQL 沙箱。
- `ListDeviceSessions(context.Context, AdminRequest, string, int) (DeviceSessionPage, error)`：Items/NextCursor/HasMore；内部 limit=0 默认50，>100截断，负数/非法 cursor 为 ErrInvalidSessionPage。S03须区分 HTTP省略与显式0，遵守 minimum=1；按冻结 HTTP schema 映射。未授权 ErrInvalidSession，存储 ErrStorage；普通 GET 沿既有 RenewRead 规则。
- `RevokeDeviceSession(context.Context, AdminRequest, string) error` 参数只取不可复用 Session.id，未知/失效 ErrSessionNotFound；`SetRevocationHook(func(string))` 仅提交后精确 ID 通知，当前 token Revoke 同路；专用自撤复核 revoked=1/期限/代次/身份、跳过续期，最终同一时刻双方检查。
- 手机、真实 WS/provider E2E 均 **NOT_RUN**，没有运行时/真机；未证明真实断连或 provider 原子解绑。P09 仍须实际映射持久化失效并在发送/回调提交前复核身份和有效性。
